# Phase 5 — Certification Marketplace

## Goal

Expand beyond K-12 into adult/professional education: OSHA safety, trade certifications, IT certs, continuing education. All delivered through the narrative engine.

## Deliverables

- **Certification Catalog** — browseable listing of certs (OSHA, Notary, Trade, IT, CE)
- **Narrative-driven prep** — each cert track wrapped in the academy theme/story
- **Assessment Engine** — practice exams, progress tracking toward cert requirements
- **Completion credentials** — printable/completable certificates of completion
- **Marketplace infrastructure** — course enrollment, payment (if monetized)

## Prerequisites

- Phase 1 through 4 core platform
- Concept graph extended to cover adult ed topics

## Research agenda

- [ ] OSHA curriculum requirements and testing format (OSHA 10, OSHA 30)
- [ ] Trade certification bodies and their prep material licensing
- [ ] IT certification exam objectives (CompTIA, AWS, etc.) — many are public
- [ ] Continuing education credit tracking rules by state
- [ ] Notary public certification requirements by state
- [ ] Marketplace payment processing (Stripe, etc.) if monetized
- [ ] Certificate generation — PDF templates with verifiable IDs
- [ ] Grant funding alignment — workforce development grants map to cert tracks

## Verification

- User can browse certification catalog and see requirements
- Narrative-driven prep module loads for at least one cert (e.g. OSHA 10)
- Practice exam scores track progress toward cert completion
- Certificate PDF generates with student name, date, and verifiable ID
- Adult learning track exists alongside K-12 tracks with separate dashboard
