# Introduction to Decimals

## Learning Objectives
- Understand decimals as another way to write fractions
- Read and write decimals to the hundredths place
- Compare and order decimals

## What Is a Decimal?

A **decimal** uses a decimal point to show parts of a whole. Each place to the right of the decimal point represents tenths, hundredths, thousandths, and so on.

```
Ones . Tenths  Hundredths  Thousandths
 3  .   5        7            2
```

The decimal 3.572 means: 3 ones + 5 tenths + 7 hundredths + 2 thousandths

## Decimals and Fractions

Decimals and fractions are two ways to write the same number.

| Decimal | Fraction |
|---------|----------|
| 0.5 | 1/2 |
| 0.25 | 1/4 |
| 0.75 | 3/4 |
| 0.1 | 1/10 |
| 0.01 | 1/100 |

## Comparing Decimals

Line up the decimal points and compare digit by digit from left to right.

> Compare 0.45 and 0.48:
> - Tenths: both are 4 (tie)
> - Hundredths: 5 < 8
> - So **0.45 < 0.48**

A helpful trick: add zeros to make the same number of decimal places.
> 0.4 = 0.40 and 0.45 — now it's easy to compare

## Practice

1. Write 3 tenths and 7 hundredths as a decimal.
2. Which is larger: 0.6 or 0.59?
3. Order from least to greatest: 0.8, 0.08, 0.88, 0.808
4. Write 0.65 as a fraction in simplest form.

## Remember

- The decimal point separates whole numbers from parts
- Each place is worth 1/10 of the place to its left
- More digits after the decimal doesn't always mean a bigger number
