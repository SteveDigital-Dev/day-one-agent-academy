# Patterns and Sequences

## Learning Objectives
- Identify and extend number patterns
- Find the rule (common difference) in a pattern
- Create patterns using a given rule

## What Is a Pattern?

A **pattern** is a sequence that follows a rule. The rule tells us how each term relates to the next.

> Example: 3, 6, 9, 12, 15...
> Rule: Add 3 each time

## Finding the Rule

Look at the **difference** between consecutive terms.

| Pattern | Difference | Rule |
|---------|-----------|------|
| 2, 4, 6, 8, ... | 2 | Add 2 |
| 5, 10, 15, 20, ... | 5 | Add 5 |
| 100, 90, 80, 70, ... | −10 | Subtract 10 |

## Extending a Pattern

Once you know the rule, continue the pattern.

> Pattern: 7, 14, 21, 28, ...
> Rule: Add 7
> Next terms: 35, 42, 49

## Creating a Pattern

Given a rule, write your own pattern.

> Rule: Start at 5, multiply by 2 each time
> Pattern: 5, 10, 20, 40, 80, 160...

## Practice

1. Find the next three numbers: 4, 9, 14, 19, ...
2. What is the rule? 81, 72, 63, 54, ...
3. Create a pattern starting at 3 with the rule "add 5"
4. Find the missing number: 16, 24, ___, 40, 48

## Remember

- Patterns can go up, down, or even alternate
- The common difference is the key to unlocking any linear pattern
- Always check: does your rule work for every term?
