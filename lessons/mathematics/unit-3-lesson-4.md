# Adding and Subtracting Decimals

## Learning Objectives
- Add decimals by lining up decimal points
- Subtract decimals using the same method
- Estimate to check if answers are reasonable

## The Golden Rule

**Always line up the decimal points** before adding or subtracting.

> Example: 3.45 + 2.7
>
> ```
>   3.45
> + 2.70   ← add a placeholder zero
> -------
>   6.15
> ```

## Step-by-Step

**Addition:**
1. Line up the decimal points
2. Add placeholder zeros so both numbers have the same decimal places
3. Add as you would with whole numbers
4. Bring the decimal point straight down

> Example: 12.6 − 4.37
>
> ```
>  12.60
> - 4.37
> -------
>   8.23
> ```

## Estimating

Round each number before calculating to get an estimate.

> 3.45 + 2.7 ≈ 3.5 + 3 = 6.5 (actual: 6.15 — close!)

If your answer is far from your estimate, check your work.

## Practice

1. 5.8 + 3.67 = ?
2. 10.4 − 6.25 = ?
3. 0.78 + 0.3 = ?
4. Estimate first, then calculate: 8.92 − 3.46

## Remember

- Line up the decimal points every time
- Add placeholder zeros to make subtraction easier
- Estimate before you calculate — it catches errors
- The decimal point goes straight down in your answer
