# Adding Fractions with Like Denominators

## Learning Objectives
- Add fractions that share the same denominator
- Simplify the result when needed
- Understand why we add numerators but not denominators

## The Rule

When fractions have the **same denominator**, adding them is straightforward:

**Add the numerators. Keep the denominator the same.**

```
a/c + b/c = (a + b)/c
```

> Example: 2/7 + 3/7 = 5/7

## Why Don't We Add Denominators?

Think of fractions as parts of the same whole. If the denominator is 7, the whole is divided into 7 parts. Adding 2/7 + 3/7 means we now have 5 of those 7 parts — the size of each part (the denominator) doesn't change.

## Mixed Numbers

A **mixed number** has a whole number and a fraction (like 2 1/3).

To add mixed numbers:
1. Add the whole numbers
2. Add the fractions
3. Simplify if needed

> Example: 2 1/4 + 1 2/4 = 3 3/4

## Remember

- Only add numerators when denominators are the same
- If the numerator equals or exceeds the denominator, convert to a mixed number
- Always simplify your answer
